# R4 manuscript snapshot

English and Chinese sources and full-quality PDFs copied without editing from the selected R4 manuscript on 13 November 2026. They identify the scientific version supported by this release. Coauthor comments, internal editing instructions and email drafts are excluded.

The TeX files use the PNGs in `../official_figures/`. To compile, copy those 14 PNGs into this folder or set the graphic search path to that folder. The supplied PDFs are the already-verified manuscript PDFs; they are not regenerated by the scientific Python workflows. Springer Nature class/style files retain their original notices and are not relicensed as author code.

The checked reference metadata and bibliography-only dark-green markup require both R4_reference_changes.tex and R4_reference_changed_keys.tex beside the manuscript source. These helpers are included.
