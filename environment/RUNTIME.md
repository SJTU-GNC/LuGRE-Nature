# Bundled runtime

`runtime/python_exact/python.exe` is the default offline runtime.

- Python 3.12.13, 64-bit Windows
- NumPy 2.5.0
- pandas 3.0.3
- Matplotlib 3.11.0
- Cartopy 0.25.0

Matplotlib 3.11.0 is material: the formal Fig3 PNG was created with that
version, and rerunning the same code under 3.10.9 changes tight-bounding-box
dimensions. The pinned runtime restores the registered Fig3 SHA256 exactly.

Launch scripts set `PYTHONNOUSERSITE=1`, `PYTHONDONTWRITEBYTECODE=1`,
`MPLBACKEND=Agg`, and a package-local `MPLCONFIGDIR` so that no user Python
installation or writable home directory is required.

Exact rendering of ED1 and ED6-ED9 also requires the Windows Arial fonts listed
in `font_requirements.json`. These proprietary operating-system fonts are not
redistributed. `verify_package.py` checks their SHA256 values before figure
generation. A different font version may produce a scientifically equivalent
figure, but not the registered PNG bytes.

The package-wide hash manifest covers the complete embedded runtime except
regenerable Python bytecode caches. `verify_package.py` additionally imports
every pinned scientific package with the embedded interpreter and verifies its
exact version.

`run_all.py` launches every figure in a fresh interpreter. This isolates
Matplotlib `rcParams` and imported-module state so one renderer cannot alter the
pixels generated by the next renderer.

For Windows systems without long-path support, copy the package to a very short
location such as `C:\LGR`. The normalized runnable task paths are short, but
some preserved historical upstream filenames are long.
